二、最优方案：三阶段，现在只做第一阶段

1
阶段一：测试 / 参赛（0 成本、0 准备、今天就能用）

用已发布链接 https://paoyouji.app.workbuddy.host/。改完内容跟我说一声，重新发布即可，链接永远不变。

再加一道保险：把单个 HTML 文件直接发给对方双击打开。这应用是纯前端 + 本地存储，零依赖、零网络，离线打开体验和在线完全一样——评审场景下这其实是最稳的一条路。

要做的事：无。
2
阶段二：正式公开地址（约 ¥70–90/年，1 小时内搞定）

买一个域名，绑到 EdgeOne 国际站（腾讯云出品，亚太节点优化，免备案、免费套餐，实测主站可达）。这是「不备案」前提下国内最靠谱的一条路。

域名建议：paoyouji.com / paoyouji.top。注意 .cn 域名不备案无法解析，别买 .cn。

注意：这一步只解决「有个像样的网址」，不解决速度——没备案只能走境外节点，国内延迟大概几百毫秒，够用但不快。

四、为什么我建议「先别备案」

三条理由，按重要性排：

  • ① 跟你的最终形态冲突。「狍游记」既定路线是微信小程序。小程序走微信云开发，静态资源放云存储，压根不需要 ICP 域名备案——它要走的是另一套「小程序备案」（在微信公众平台提交，跟网站备案是两回事）。现在花 3 周办域名备案，等小程序上线后这套域名就成了闲置资产。
  • ② 个人备案的网站不能商业化。按规定个人备案站点不得有会员注册、在线交易、支付接口，也不能做企业名义的商业宣传。你现在是纯工具（不代订、不收佣）没问题，但哪天要接商业化，个人主体得推翻重来，改企业备案。
  • ③ 备案是长期负债，不是一锤子买卖。拿到号后要持续合规：主体信息、网站内容、域名实名都要一致，管局会不定期核查；还要在开通后 30 日内办公安联网备案。
什么时候才该办？只有一种情况——你确定「狍游记」要长期做独立 Web 品牌站（不只是小程序），且需要国内秒开。到那时再办，一点不晚。

五、真要备案的话，准备这些

费用
官方零费用。唯一可能的成本是备案云资源（见下）。
周期
接入商初审 1–4 工作日 + 管局终审 4–15 工作日，合计约 5–19 个工作日。
必备材料
身份证正反面原件照片 · 域名证书（注册商下载）· 人脸活体核验（小程序端，约 3 分钟）· 应急手机与邮箱 · 部分省份需手写承诺书
关键前置
域名实名认证必须与备案主体姓名完全一致——不一致是最常见驳回原因，改完还要等 3 天同步期。
网站名称
不得含「中国 / 中华 / 国家」等受限词。建议「狍游记东北旅行助手」。
拿号后
首页底部悬挂备案号并链接工信部系统；30 日内办公安联网备案。

好消息：不用为了备案买服务器

腾讯云 CloudBase 环境本身就能作为备案云资源，无需额外购买云服务器。需同时满足三个条件：

  • 套餐为个人版及以上（免费体验环境不支持）
  • 云环境剩余有效期 ≥ 6 个月
  • 该环境已开启云托管固定 IP
这条对你是量身定做的——小程序本来就要用云开发环境，同一个环境既能跑小程序后端，又能拿来办备案，不额外花钱。

六、小程序路线要走的另一套备案

如果你按既定路线做微信小程序，需要的是「移动互联网应用程序备案」，与网站 ICP 备案并行、材料更简单：

  • 提交入口：微信公众平台（小程序后台），不是云厂商备案系统
  • 材料：主体证件（个人身份证 / 企业营业执照）+ 负责人人脸核验 + 小程序名称与内容说明
  • 生效节点：小程序备案是发布上架的前置条件，未备案无法过审上线
所以时间线可以这样排：现在纯 Web 测试 → 确认要做小程序 → 注册小程序 → 提交小程序备案 → 上架。全程不需要域名 ICP 备案。

七、现在就能做的三件事

  1. 什么都不做，直接用现链接测。 https://paoyouji.app.workbuddy.host/ —— 已实测可用。
  2. 把单文件 HTML 发给测试者离线打开，作为评审场景的兜底。
  3. 建个 GitHub 私有仓库做版本备份，之后每次改动提交一次，随时能回滚。
等测试结果回来、确定「要不要长期做独立 Web 站」之后，再决定买域名和备案。这个顺序能帮你省下至少 3 周和一个域名的钱。
